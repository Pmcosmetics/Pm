# PM Cosmetics HuB — Orders Admin

لوحة متابعة خفيفة تعمل على GitHub Pages وتقرأ `orders.csv` للعرض والبحث والتصفية.

## الوصول

بعد نشر GitHub Pages من `main`/`pages` تكون اللوحة تحت:

`/admin/`

## الوظائف

- عرض الطلبات في جدول.
- البحث برقم الطلب/المنتج/الحالة.
- فلترة حسب الحالة.
- تحديث البيانات.
- تنزيل `orders.csv`.
- فتح واتساب برسالة جاهزة.
- فتح Issue جاهز لتسجيل `Mark Shipped` وإضافة الشحن/التتبع.
- فتح محرر GitHub لتعديل `orders.csv` يدوياً.

## دورة الحالة

`pending → confirmed → paid → shipped → delivered`

والإلغاء: `cancelled`.

## قاعدة أمان مهمة

GitHub Pages موقع عام، و`orders.csv` الموجود في مستودع عام يمكن الوصول إليه عبر GitHub/raw. لذلك **لا تُدخل بيانات العملاء الحقيقية (الاسم، الهاتف، العنوان، رسائل واتساب) في هذا الملف المنشور**.

استخدم الملف حالياً كقالب/بيانات اختبار فقط. للطلبات الحقيقية ننقل source-of-truth إلى مخزن خاص (Google Sheets خاص، Airtable/Notion بصلاحيات مناسبة، أو backend + database)، ثم نربط اللوحة به.

## التشغيل اليدوي الحالي

1. استقبل الطلب على واتساب.
2. أنشئ `order_id`.
3. سجّل البيانات في مخزن الطلبات الخاص.
4. حدّث الحالة فوراً بعد كل حدث.
5. عند الشحن: سجّل شركة الشحن ورقم التتبع.
6. عند التسليم: حوّل الحالة إلى `delivered`.

> لوحة `/admin/` الحالية هي MVP للواجهة والتشغيل على بيانات غير حساسة، وليست نظام مصادقة أو مخزناً آمناً لبيانات العملاء.
